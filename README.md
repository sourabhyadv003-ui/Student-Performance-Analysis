# Student Performance Analysis using Python and SQL

## Project Overview

This project analyzes student performance using Python, Pandas, SQL, Matplotlib, and Seaborn.

The objective is to understand student performance and identify relationships between attendance, study hours, assignment scores, and exam scores.

## Dataset

The dataset contains:

- Student ID
- Student Name
- Age
- Gender
- City
- Attendance Percentage
- Study Hours Per Day
- Assignment Score
- Exam Score
- Grade

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- MySQL
- SQL
- Excel

## Analysis Performed

### SQL Analysis

SQL was used to:

- Calculate total number of students
- Calculate average, highest and lowest exam scores
- Analyze performance by city
- Analyze grade distribution
- Analyze attendance and study-hour categories
- Identify high and low performing students
- Compare assignment and exam scores

### Python Analysis

Python and Pandas were used for:

- Data loading
- Data inspection
- Data cleaning
- Statistical analysis
- Correlation analysis

Matplotlib and Seaborn were used for:

- Study Hours vs Exam Score
- Attendance vs Exam Score
- City-wise Average Exam Score
- Grade Distribution
- Correlation Heatmap
- Study Category vs Exam Score
- Exam Score Distribution

## Key Insights

- Study hours showed a positive relationship with exam scores.
- Assignment scores showed a positive relationship with exam scores.
- Attendance showed a weaker relationship with exam scores in this dataset.
- Correlation analysis helped identify variables associated with exam performance.

## Conclusion

This project demonstrates the use of SQL for database analysis and Python for data cleaning, statistical analysis, and visualization.

The project provides insights into factors associated with student academic performance.
